# TruthLens AI

**TruthLens AI** is a deepfake image detection system powered by a fine-tuned Xception CNN. Upload any image and the model tells you whether it is a real photograph or an AI-generated / deepfake image, along with a confidence score.

---

## Features

- Detects **real vs. AI-generated / deepfake** images with a single click
- Returns a **confidence percentage** for every prediction
- **Drag-and-drop** web interface — no technical knowledge required
- **User feedback loop** — correct predictions are automatically saved back into the training dataset
- Built on **Xception** (ImageNet pre-trained), fine-tuned for deepfake detection

## Quickstart

### 1. Train the model

Add your own images to `dataset/real/` and `dataset/fake/`, then run:

```bash
python src/train.py
```

This trains the model for 10 epochs and saves it to `models/deepfake_xception_model.keras`.

A **pre-trained stub model** is included so the app can start immediately. Replace it with a model trained on your full dataset for accurate results.

### 2. Run the web app

```bash
python app/app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser, upload an image, and click **Analyze Image**.

### 3. Command-line prediction (optional)

```bash
python src/predict.py --model models/deepfake_xception_model.keras --image path/to/image.jpg
```

## Model Architecture

| Layer | Details |
|---|---|
| Base | Xception (ImageNet weights, frozen) |
| Pooling | GlobalAveragePooling2D |
| Normalization | BatchNormalization |
| Dense | 256 units, ReLU |
| Regularization | Dropout (0.5) |
| Output | Dense(1, sigmoid) |

- **Input size:** 299 × 299 × 3
- **Output:** Probability score — `> 0.5` → Real, `≤ 0.5` → Fake
- **Loss:** Binary cross-entropy
- **Optimizer:** Adam (lr = 0.0001)
